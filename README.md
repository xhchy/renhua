# 人话 · 手机 Linux 助教

> 手机上跑 Linux 的门槛不在「能不能跑」，在「看不懂」。

Termux 给你一个黑框，Andronix 装完还是黑屏桌面，Termux:X11 给你配置地狱。
现有方案全在解决「能不能跑」，没有一个在解决「**看不看得懂**」。

这个 App 只做一件事：

**在你敲下一条命令之前，用中文告诉你它要干什么、会不会弄坏东西；跑完之后，把那一堆英文说成人话。**

---

## 它长什么样

三个预设任务，每个都是「点一下，看它一步步干」：

| 任务 | 做完你会知道 |
|---|---|
| 给手机做个体检 | 架构、内存、剩余空间、你的权限——装任何东西前必须先知道的四项 |
| 查空间去哪了 | `df` 只说盘满了，这个任务把它落到具体目录 |
| 读出机型和系统版本 | 报 Bug、查兼容、找教程都要这三个值 |

再加一个「自己敲一条」：边打边解释，逐字拆开开关。

每一步是一张卡片，四层信息：

```
① 这一步想搞清楚什么        ← 用问题写，不用功能写
② $ uname -a                ← 真正要跑的命令
③ 跑之前先讲清楚            ← 动词 / 对象 / 每个开关 / 为什么用它 / 结果怎么看
④ 翻译成人话                ← 从原始输出里提炼出的几句结论
```

`df` 的 92% 会被翻译成「偏紧，建议清一些东西」；`cat /proc/meminfo` 的 7781234 kB 会被翻译成「可用内存 0.4 GB / 共 7.4 GB，可用不到一成」。

## 三条设计原则

**① 不认识就说不认识。**
知识库里没有的命令，会明确标出「这条不在我的知识库里，上面的拆解只讲了结构，含义不确定」。认识的命令遇到不认识的开关，也会单独标出来。

新手最怕的不是看不懂，是**看到一个自信但错误的解释**，然后照着错的去操作。所以宁可留白，不猜。

**② 先讲后跑，不是跑完再补解释。**
解释在读到你输入的那一刻就生成，执行之前你就能看到这条命令要动什么。风险分三级：只读 / 会改东西 / 危险（`rm -rf /`、`dd of=`、`reboot` 这类会被标成红色）。

**③ 不需要 root，也不需要 Termux。**
命令直接跑在 App 自己的沙箱里（`/system/bin/sh`），安卓每个 App 自带这个 sh。代价是看不到别人的文件——**这正是新手该有的边界**，也是这个 App 不需要申请任何危险权限的原因。

## 已知边界（说清楚，不藏）

- **目前只能跑只读命令**，还没接 proot 环境，装不了 Python/Node。这是 MVP 的第一阶段：先验证「解释到底有没有用」。
- **`ps` 类命令在安卓上受限**，普通 App 只能看到自己的进程，输出会比你预期少，这是系统限制不是 bug。
- **解释是本地规则库，不是大模型**。覆盖 20 个常用命令，超出的会明说。接大模型是下一阶段的事——但那之前得先证明规则库不够用。
- **只在 Android 上验证过**。Windows/macOS 桌面端没测。

## 跑起来

需要 Flutter 3.27+（本项目在 3.47.7 上验证）。

```bash
flutter pub get
flutter test            # 24 个测试：命令拆解 / 风险判定 / 解释 / 结果翻译 / 界面
flutter run             # 连真机或模拟器
flutter build apk --debug
```

零第三方依赖，只用 Flutter 自带能力。

## 代码结构

```
lib/
├── core/                 纯 Dart，不依赖 Flutter，可单测
│   ├── shell_cmd.dart    命令拆解（动词/对象/开关）+ 三级风险判定
│   ├── knowledge.dart    20 个命令的中文知识库 + 报错中文对照表
│   ├── explain.dart      生成「讲清楚」的每一行
│   ├── runner.dart       沙箱内执行，带超时和输出上限
│   ├── interpret.dart    把原始输出提炼成人话结论
│   └── tasks.dart        三个预设任务
└── ui/                   界面
```

核心逻辑全部在 `core/`，不 import Flutter——所以能被 `flutter test` 直接跑，不需要模拟器。

## 为什么做这个

手机端开源项目里，能爆的全部是「帮用户绕开某种限制」：v2rayNG 66k、cleanyourtv 60k、legado 47k、gkd 45k。
反过来，没有限制可绕的纯工具类，天花板低得离谱。

而「手机跑 Linux」这件事，限制一直都在——**限制是学习成本本身**。
